- `identity/` — Fase 1
- `messaging/` — Fase 2
- `moderation/` — Fase 2
- `academics/` — Fase 3
- `payments/` — Fase 4
- `notifications/` — Fase 4

Convenciones de estructura interna en `CONTRIBUTING.md`.
